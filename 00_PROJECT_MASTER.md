# AI Masterpiece — Project Master

## Mission
Build a powerful, practical, local-first personal AI system that grows from a useful local assistant into a modular system with memory, tools, agents, automation and voice.

## Current Phase
**Phase 0 — Requirements, architecture and planning**

No production installation is authorised yet. Research and decisions come first.

## Hardware
- CPU: AMD Ryzen 5 5600X
- GPU: NVIDIA RTX 3070
- Motherboard: ASUS TUF B450-Plus Gaming
- Storage: multiple SSDs

Strategy: use existing hardware first and benchmark before upgrading.

## Direction
- Local-first
- Initial AI inference local-only
- Privacy-conscious
- Secure by default
- Modular
- Portable
- Maintainable
- Affordable
- Upgradeable
- Evidence-driven
- Simple before complex

## Planned Capabilities
Local LLMs, model routing, Boss/Personal AI, specialist workers, long-term memory, RAG, Obsidian, MCP, skills, agents, web research, coding, controlled computer interaction, voice, automation, monitoring and security.

## Core Principles
- Capability does not equal permission.
- The AI never knowingly guesses.
- If it does not know, it researches; if research cannot resolve it, it asks or says it does not know.
- Nothing consequential executes without appropriate explicit authority.
- The AI is a layer on top of the machine, never the root of control.
- Data must remain recoverable without the AI.
- Build incrementally and prove each layer before adding the next.

## Engineering Workflow
**Build:** PLAN → BUILD → TEST → VERIFY → DOCUMENT

**Troubleshoot:** OBSERVE → HYPOTHESISE → TEST → CHANGE → VERIFY

**Decide:** REQUIREMENTS → RESEARCH → COMPARE → RECOMMEND → DECIDE → DOCUMENT
