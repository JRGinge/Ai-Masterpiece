# AI Masterpiece — Agents & Skills

## Principle
Use agents only where autonomy provides real value. Prefer deterministic automation for predictable tasks.

## Candidate Workers
Research, coding, reasoning, vision, data analysis, document processing, file organisation and system monitoring.

## Every Agent Must Define
Purpose, trigger, inputs, outputs, model, tools, permissions, memory, failure behaviour and approval requirements.

## Skills
Reusable procedures should define when to use them, required information, steps, tools, output format and safety rules.

## Authority
Agents cannot grant themselves permission. Autonomy never bypasses the security layer.

## Status
Architecture only. Do not implement a large agent system before the basic assistant/tool layer is proven.
