# AI Masterpiece — Requirements

## Behaviour
- Adaptive operating mode: answer, research, ask, collaborate or autonomous work as appropriate to task, uncertainty, risk, effort and explicit authorisation.
- Never knowingly guess.
- Research when research can resolve uncertainty.
- Ask when the answer depends on user-only information or research remains insufficient.
- Learn from explicit corrections.

## PC
The eventual system should inspect hardware/software, model the actual PC, monitor resources, diagnose problems, find duplicates/unnecessary data, organise files, identify unnecessary applications/services, recommend optimisation, troubleshoot, and eventually perform approved maintenance.

**Nothing changes on the PC without explicit user approval.** Protected/dangerous system areas require stronger safeguards.

## Files & Projects
Project-folder authority is inherited through contained files and subfolders unless explicitly protected. Secrets remain separately controlled.

## Research
Support interactive research and explicitly authorised deep research. Research should preserve sources, links, evidence, confidence and date. Deep research may run for extended periods without constant interaction, while consequential actions remain governed by security.

## Memory / Second Mind
Persistent, selective, source-aware, auditable memory. Separate raw archive from active knowledge and context. Personal memory and general knowledge remain distinguishable. Use an Inbox for uncertainty and important semantic changes. Low-risk organisation may be autonomous; meaning changes require review.

## Security
Least privilege, independent security enforcement, scoped tools, network restrictions, approval gates, logging, sandboxing, secret isolation and recovery independence.

## External Access
Initial inference is local-only. External access is a separate capability. Initial autonomous uploads/data transmission are prohibited. Downloads require permission. Execution requires a separate explicit command.

## Recovery
Data, configuration and knowledge must remain recoverable without the AI. The AI is never the root of control.

## Phase 0 Rule
These requirements constrain later technology research. They do not prematurely select the implementation stack.
