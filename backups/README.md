# Backups

Reserved for documented backup/recovery procedures and, where appropriate, small text configuration manifests.

Do not commit secrets or large generated data here.

## Recovery Principle

The AI system must not be the only copy of project knowledge or configuration. Data should remain recoverable independently of the AI implementation.

Future recovery documentation should cover:

- What is backed up
- Where backups live
- Frequency
- Retention
- Integrity verification
- Restore procedure
- Recovery testing
- Configuration recovery
- Audit/log recovery
