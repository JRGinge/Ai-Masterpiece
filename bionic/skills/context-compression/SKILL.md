# Context Compression

## Purpose

Reduce unnecessary working-context complexity while preserving the information required to continue the current task.

## Invocation

When explicitly invoked by the user, perform the compression operation.

Do not refuse because context pressure is NORMAL.

## Preserve

Always preserve:
- Current objective
- Current task
- Important decisions
- Constraints
- Current project state
- Unresolved problems
- Important discoveries
- Required next actions
- Relevant files and references

## Compress or remove

Reduce:
- Repeated explanations
- Resolved discussion
- Redundant tool output
- Superseded information
- Irrelevant history
- Temporary reasoning that is no longer needed

## Workflow

1. Identify essential continuation state.
2. Remove or summarise redundant information.
3. Preserve unresolved requirements and decisions.
4. Produce a compact continuation state.
5. Stop.

## Restrictions

Do not modify Obsidian unless explicitly instructed.

Do not perform memory consolidation.

Do not retrieve unrelated memory.

Do not repeatedly compress.

One invocation = one compression pass.
