# Memory Consolidation

## Purpose

Organise durable information from current or specified work into persistent memory.

## Invocation

When explicitly invoked by the user, perform one consolidation pass.

Do not refuse because context pressure is NORMAL, no milestone has been detected, or the session is not finished. Those conditions are relevant only when Bionic is deciding whether to invoke this skill autonomously.

## Workflow

1. Review the relevant current work.
2. Identify durable information.
3. Compare it with existing memory.
4. Merge duplicate information.
5. Update existing notes where appropriate.
6. Create new notes only where necessary.
7. Remove or mark obsolete information only when its replacement is clear.
8. Verify important changes.
9. Stop.

## Anti-bloat

Do not save the conversation verbatim.

Prefer concise durable knowledge.

Do not create duplicate notes.

Do not reorganise unrelated areas of the vault.

## Hard stop

Perform one consolidation pass.

Do not automatically invoke another memory skill after completing the pass.
