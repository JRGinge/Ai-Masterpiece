# Memory Retrieval

## Purpose

Retrieve relevant persistent information from Obsidian.

## Invocation

When explicitly invoked by the user, perform retrieval.

Do not refuse because context pressure is NORMAL.

When invoked autonomously, retrieve information only when it is relevant to the current task.

## Workflow

1. Determine what information is needed.
2. Search Obsidian.
3. Prefer current and authoritative information.
4. Prefer project-specific information when applicable.
5. Return only the relevant information.
6. Stop.

## Context discipline

Do not dump entire notes or projects into context unless specifically necessary.

Prefer:
- Current state
- Relevant decisions
- Constraints
- Known problems
- Important discoveries
- Next actions

Avoid duplicate information, superseded decisions, unrelated notes, and large amounts of irrelevant history.

## Restrictions

This skill is read-only.

Do not modify Obsidian.

Do not capture memory.

Do not consolidate memory.

Do not compress context.

Do not invoke another skill.
