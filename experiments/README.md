# Experiments

Experiments validate architecture, models, performance and security assumptions before decisions are locked.

## Required Record

- Date
- Goal / hypothesis
- Environment
- Component/model/version
- Configuration
- Test procedure
- Measurements
- Result
- Interpretation
- Limitations
- Decision impact
- Reproduction notes

## Rule

An experiment is evidence, not automatically a decision. Important conclusions should be promoted to the Decision Log only after evaluation.
